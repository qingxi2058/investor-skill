# investor-skill

像顶级投资人一样，专门拷问一个创业想法、副业项目或内容方向到底靠不靠谱。

它不是来鼓励你空想的，也不是来一棍子打死你的。定位是**副业排雷员**：先帮你看清想法哪里不成立，挑出真风险，再给你一条能立刻动手验证的最稳第一步。

> 核心信条：**别 All in，先用一周、几百块小成本去试。** 验证不过就掉头——几百块买个真相，比烧半年值。

## 适合什么场景

- 想判断一个副业值不值得做
- 想让 AI 像投资人一样做尽职调查（DD）
- 在拍视频、做内容、写方案前，先过一轮硬核筛选
- 评估一个内容方向 / 账号方向 / 现成 Skill 到底有没有做头

## 它会做什么

按固定顺序把你的项目问穿，每个维度都带人话框架和犀利提问：

1. **真需求**——是真痛点还是伪命题，高频，或低频但高客单
2. **时机 Why Now**——为什么是现在做，最近什么变了
3. **竞争护城河**——谁在做、你凭什么守得住（早期降权）
4. **一单经济账**——一单净赚多少、获客花多少、还要算时间利润账
5. **真实验证**——有没有真实用户、真付费、真传播
6. **凭什么是你**——你的不公平优势、扛压能力
7. **冷启动**——前 100 个用户从哪来
8. **致命风险 + 副业三件套**——时间 / 交付口碑 / 平台合规

**结论不靠死板分数，靠"证据等级"**：

| 等级 | 你手里有什么 | 倾向 |
|---|---|---|
| L0 无证据 | 只有想法 | 待定，先去做最小验证 |
| L1 有反馈 | 有人说"想要" | 待定，去收第一单 |
| L2 有付费 | 收到真钱 | 可做，小步放大 |
| L3 可复购 | 有人回头买/转介绍 | 值得加注 |

最后给三种结论 + 一条 7 天能动手的验证动作：🟢 可做 / 🟡 待定 / 🔴 不做。

## 这个版本的特点

- 不会顺着用户说，也不拿"感觉"当证据
- 不只提问题，会落明确结论 + 可行动的下一步
- 专为**普通副业人**校准：讲人话不讲 VC 黑话，泼冷水后必给小路
- 用证据等级取代伪科学分数，鼓励小步验证而非纸面判死刑

## 迭代记录

- **v1（初版）**：8 维 DD + 三色结论。
- **v2（内容加厚）**：补 6 个人话版投资人框架（真需求三连问 / Why Now / 一单经济账 / 四种护城河 / 凭什么是你 / 冷启动）、按维度犀利提问库、2 个完整实战范例。
- **v3（三方会诊校准，本版）**：经 Claude + Codex + Gemini 三方独立评审 + 公开 VC DD 框架对照，发现初版"过于 VC 化、不适合普通副业人"。据三方共识修正：
  1. **定位软化**——从"投资判决机"改为"副业排雷员"，泼冷水后必给最小验证小路；
  2. **修硬错**——删掉"高频刚需才撑得起生意"（副业多是低频高客单）；
  3. **评分改证据等级**——废掉刚性 7/4 分门槛，分数仅作参考，真正定结论看 L0→L3 证据；
  4. **补副业三件套风险**——时间利润账 / 交付口碑 / 平台合规；
  5. **护城河早期降权 + 新增"7 天最小验证"框架**——L0/L1 阶段不判死刑，而是设计验证动作。
