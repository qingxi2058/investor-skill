# investor-dd-skill

像顶级投资人一样，专门拷问一个创业想法、项目或副业到底靠不靠谱。

它不是来鼓励你的，也不是来陪你空想的。它的作用只有一个：尽快把一个想法问穿，然后给出明确结论。

## 适合什么场景

- 想判断一个副业值不值得做
- 想让 AI 像投资人一样做尽职调查
- 在拍视频、做内容、写方案前，先过一轮硬核筛选
- 拿到一个现成 Skill 或项目，想知道它到底有没有做头

## 它会做什么

它会按固定顺序拆你的项目：

1. 市场是不是足够大，而且是真的
2. 痛点是不是真的痛，用户会不会掏钱
3. 谁已经在做，你到底凭什么赢
4. 你准备怎么赚钱，能赚多少
5. 有没有真实验证，不是嘴上说说
6. 你一个人能不能扛住执行
7. 最可能死在哪
8. 什么结果才算成功

最后只会给三种结论：

- 可投
- 待定
- 不投

## 安装

```bash
npx skills add qingxi2058/investor-dd-skill
```

## 触发方式

下面这些说法都适合直接调用：

- 帮我看看这个想法靠不靠谱
- 帮我做 DD
- 像投资人一样问我
- 帮我判断一下这个项目
- 这个 Skill 值不值得做

## 示例

用户：

> 我想做一个 AI 帮人写小红书文案的副业，主要卖给不会写内容的个人创业者。

输出重点：

- 先把目标用户、痛点、竞品、收费方式问清
- 再判断是不是“看起来热闹，实际上很难收钱”
- 最后直接给结论和下一步建议

## 这个版本的特点

- 不会顺着用户说
- 不拿“感觉”当证据
- 不只提问题，也会落明确结论
- 特别适合拿来筛 Skill 选题、短视频选题和副业方向
